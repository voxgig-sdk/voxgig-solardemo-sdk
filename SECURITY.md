# Security Policy

## Reporting a vulnerability

Please report security issues to security@voxgig.com.

Do not open public GitHub issues for suspected vulnerabilities. We aim to
acknowledge reports within 3 business days.

For non-security bugs, use the issue tracker: https://github.com/voxgig-sdk/voxgig-solardemo-sdk/issues

## Scope

This policy applies to the generated Voxgig SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, Clojars, NuGet, pub.dev, Hex, hackage, Maven Central, reservoir, opam, CPAN, crates.io, Swift Package Manager, the Go module, and git tags).

This is an unofficial SDK for the Solar System public API, generated by
Voxgig. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
